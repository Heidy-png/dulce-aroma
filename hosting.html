Web Hosting y Dominios

Para que una página se vea en internet necesita estar guardada en un servidor siempre encendido (hosting) y tener una dirección fácil de recordar (dominio).

Web Hosting

Es el servicio que alquila espacio en un servidor para guardar los archivos del sitio.

TipoDescripción
CompartidoMuchos sitios usan el mismo servidor. Es barato, pero con recursos limitados.
VPSServidor virtual con recursos propios. Da más control y rendimiento.
NubeVarios servidores conectados. Crece según la demanda y es muy estable.
¿Cómo funciona Vercel? Vercel es una plataforma en la nube ideal para sitios estáticos (HTML, CSS y JS). Se conecta a un repositorio de GitHub y, cada vez que haces un commit, publica automáticamente la nueva versión en una URL como nombre-proyecto.vercel.app.

Dominios

  • Nombre de dominio: la dirección legible de un sitio (ej. dulcearoma.com). Reemplaza a la dirección IP numérica.
  • TLD: la terminación del dominio: .com (comercial), .net (redes), .org (organizaciones).
  • Subdominio: prefijo antes del dominio, como pedidos.dulcearoma.com.

Propagación DNS

El DNS funciona como una agenda que traduce el dominio a la IP del servidor. Cuando se cambia, la actualización tarda de minutos a 48 horas en llegar a todos los servidores del mundo; a eso se le llama propagación.

Escribes el dominio→Servidor DNS→Devuelve la IP→Se carga el sitio
