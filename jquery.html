jQuery

jQuery es una librería de JavaScript creada en 2006 por John Resig. Nació porque en esa época cada navegador funcionaba distinto y escribir JS puro era largo y difícil. jQuery prometía "escribir menos y hacer más".

Sintaxis básica

Todo empieza con el símbolo $: seleccionas un elemento y le aplicas una acción.

$("selector").accion();
$("#caja-demo").fadeOut();

Ventajas y desventajas

VentajasDesventajas
Código corto y fácil de leer
Animaciones listas para usar
Funciona igual en todos los navegadores		 Es una librería extra que hay que cargar
JS moderno ya hace casi todo lo mismo
Cada vez se usa menos en proyectos nuevos

Efectos típicos

Promoción: ¡2x1 en frappés los viernes!
$("#b1").click(function(){ $("#caja-demo").fadeIn(); });
$("#b3").click(function(){ $("#caja-demo").slideToggle(); });
