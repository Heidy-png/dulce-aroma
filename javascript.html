JavaScript (JS Vanilla)

JavaScript es un lenguaje de programación que hace que las páginas web cobren vida: permite reaccionar a clics, validar formularios, mostrar mensajes y cambiar el contenido sin recargar la página.

Conceptos básicos

  • Variable: guarda un dato (let precio = 3.5;).
  • Función: bloque de código que se puede reutilizar.
  • Evento: algo que hace el usuario, como click o mouseover (hover).

Ejemplo práctico

let total = 0;
function pedir(precio){
  total = total + precio;
  document.getElementById("total").textContent = "Total: $" + total.toFixed(2);
}

La función pedir suma el precio al total y lo muestra en pantalla. Pruébalo:

Total: $0.00
