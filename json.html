JSON (JavaScript Object Notation)

JSON es un formato de texto ligero para guardar e intercambiar datos. Es el estándar porque es fácil de leer para las personas, fácil de procesar para las máquinas y lo entienden casi todos los lenguajes de programación.

Estructura básica

  • Pares clave-valor: "nombre": "Cupcake"
  • Objetos: van entre llaves { }
  • Arreglos: listas entre corchetes [ ]

Objeto JS vs. cadena JSON

Objeto de JavaScriptCadena JSON
const postre = {
  nombre: 'Cupcake',
  precio: 2.5,
  sabores: ['fresa','vainilla']
};
 
{
  "nombre": "Cupcake",
  "precio": 2.5,
  "sabores": ["fresa","vainilla"]
}

En JSON las claves siempre llevan comillas dobles y no se permiten comentarios.

Conviértelo tú mismo

Presiona el botón...
const texto = JSON.stringify(postre);   // objeto -> JSON
const objeto = JSON.parse(texto);       // JSON -> objeto

JSON y las APIs

Cuando una app necesita datos (por ejemplo el menú de postres), el navegador envía una petición al servidor o API. El servidor responde con JSON y el JavaScript de la página lo convierte en objetos para mostrarlo en pantalla.

Navegador→ petición →Servidor / API→ respuesta JSON →Página actualizada
fetch("https://api.ejemplo.com/postres")
  .then(res => res.json())
  .then(datos => console.log(datos));
